# Codex 语音提醒

一个运行在 Mac 菜单栏里的本地语音提醒应用。Codex 有结果、需要回答或等待人工审批时，喊一声“老板”，直到你接手。

第三方工具，与 OpenAI 官方产品无隶属关系。

[下载 v0.6.0-beta.1 DMG](https://github.com/superslash-rico/codex-voice/releases/download/v0.6.0-beta.1/CodexVoice-0.6.0-beta.1-universal.dmg) · [全部发行文件](https://github.com/superslash-rico/codex-voice/releases/tag/v0.6.0-beta.1) · [更新日志](CHANGELOG.md)

## 安装与重新打开

1. 下载 DMG，将 **Codex 语音提醒.app** 拖到 **Applications / 应用程序**。
2. 从应用程序打开，或按 `⌘ Space` 搜索 **Codex 语音提醒**。
3. 点击菜单栏波形图标打开面板。底部设备名可以选择播报扬声器。
4. 在设置里点击 **连接 Codex**，阅读说明后安装本地观察器。
5. 在 Codex CLI 的 `/hooks` 中审阅并信任这 5 个提醒观察器。

误退出后，再次从应用程序或 Spotlight 打开即可。设置中的 **登录后自动启动** 可在每次登录 Mac 时启动应用。关闭面板只收起窗口，**退出应用** 才结束本次运行。

应用内已包含 Python 运行环境，使用者无需安装 Python、Homebrew 或填写 API Key。

### 从旧版升级

在旧版设置中点击 **退出应用**，再把新版拖入 **应用程序**，选择替换同名应用，重新打开即可使用新功能。请保持原安装路径 `/Applications/Codex 语音提醒.app`；声音、扬声器、提醒规则、暂停及登录自启等设置保留，新配置项使用默认值。

已有的 5 个观察器指向同一路径时可继续使用，无需重新授权。首次安装、改变应用路径或连接失效时，仍需完成上述连接与 `/hooks` 审核。卸载运行数据会清除设置，请勿将旧版与新版同时运行。

用量功能还需要本机已安装支持账号用量接口的官方 Codex，并使用 ChatGPT 账号登录；条件不满足时显示 `—`，不影响任务提醒。

### 当前测试版边界

- macOS 13 及以上，安装包含 `arm64` 与 `x86_64` 两种架构。
- Apple 芯片 Mac 实机验证；Intel 和较旧 macOS 版本仍需实机验收。
- 尚未完成 Apple Developer ID 签名与公证。首次打开可能受到系统提示或阻止；请核对来源与校验值后，按 macOS 自身的安全提示处理。安装包不关闭 Gatekeeper，也不移除隔离属性。
- 需要支持 Hooks 的本地 Codex。若 `/hooks` 不可用，请检查 Codex 版本与功能设置；受管环境也可能禁止用户观察器。
- 当前适配本机同一用户的本地聊天。云端、远程执行、连接器特殊审批和纯文字提问不保证覆盖。Codex 内部本地事件格式升级后可能需要更新适配。

## 日常操作

- **已接手 / 知道了**：停止这一条提醒；审批仍由你在原聊天中处理。
- **全部已接手**：停止全部当前提醒，面板自动收起。新提醒到来时再次出现。
- **稍后**：选择 5、15 或 30 分钟后再提醒。
- **暂停提醒**：保留事项，暂时静音；默认 15 分钟，支持选择及自定义时长，也可提前恢复。
- **扬声器按钮**：再次播报当前事项。
- **试听一下**：创建测试提醒，按 5、10、15 秒间隔重复，点“已接手”停止。
- **提醒总开关**：关闭后立即停喊并清空当前提醒，重新开启只接收新事项。

普通提醒第一次播报后，默认依次间隔 30 秒、60 秒，再每隔 3 分钟重复。不同聊天分别接手，审批与提问优先。

### 声音与重复规则

在 **设置 → 声音与规则 → 调整** 中，可以选择本机系统音色、调整语速（100–300）、修改称呼（最多 20 个字，留空则不加称呼），并设置三档重复间隔（每档 5–3600 秒）。首次立即播报，之后依次等待三档间隔，最后一档持续重复，直到接手。

修改自动保存，重启后恢复；“恢复默认”会回到 Tingting、语速 185、“老板”和 30 / 60 / 180 秒。修改间隔也适用于正在等待的普通提醒，已选“稍后”的时间保留。原有“试听一下”仍使用 5 / 10 / 15 秒的测试节奏。

此页的 **试听声音** 只播放一次，可随时停止，不增加待处理事项。试听使用当前扬声器，并遵守总开关和暂停；正在播报实际提醒时，请等播报结束。系统新增音色后点击 **刷新音色**。未安装或已移除的音色会提示重新选择。

开关在失焦后仍按实际状态显示：开启为绿色、关闭为灰色。面板通过顶部小三角指向菜单栏图标，并随图标定位。卡片右侧的大按钮方便接手，结果卡片的“知道了”以红底白字突出显示。

暂停按钮右侧箭头提供 5、15、30、60、120 分钟及 **自定义时长**，可输入 1–1440 分钟。所选时长会保存，下次一键暂停直接使用；自定义页支持 **仅保存** 和 **保存并暂停**。仅保存不改变正在进行的暂停，再次暂停会从现在重新计时。

本版构建与验证范围见 [验证记录](docs/VALIDATION.md)，开发方法见 [本地开发记录](docs/LOCAL_DEVELOPMENT.md)。

### 自动恢复、分类提醒与定时免打扰

在 **设置 → 按类型设置提醒** 中，任务完成、等待审批、需要回答、异常关注可分别设置语音开关、持续播报或最多 1–99 次，以及独立的三档 5–3600 秒间隔。每张卡片修改后点击 **保存**；默认沿用原有的持续播报和全局间隔。限次设为 1 即只播一次。

关闭某一类语音或达到次数上限后，待办卡片仍保留，不会代替你接手或审批。手动重播、主动选择“稍后”仍可要求再播一次，且遵守总开关、手动暂停和定时免打扰。额度重置和低额度提醒保持单次播报，在用量详情中独立设置。

在 **设置 → 定时免打扰** 中，设置开始、结束时间和每周日期，点击 **保存** 后生效。默认关闭，预填每天 23:00–09:00；按本机时间执行。跨午夜的时段属于开始日期，例如勾选周一时，会从周一 23:00 持续到周二 09:00。

免打扰期间保留卡片，时段结束后只播报仍未处理的事项。可单独勾选 **允许审批提醒出声**；该例外仍受分类语音开关、播报次数、手动暂停及总开关约束。普通试听和额度消息在免打扰期间保持安静。

菜单栏应用运行时会自动管理后台播报服务：异常退出后按 1、2、5、10、30 秒重试，五分钟内最多自动重试五次；启动超过 30 秒或运行期间超过 20 秒没有状态更新时，也会检查并重启。连续失败后显示提示，可手动重新连接。主动退出应用仍会结束本次运行。

未接手事项、已处理标记、暂停及稍后期限、事件读取位置会保存到本机。服务恢复后先核对停机期间的后续回复、工具完成及归档状态，避免重复提醒已经处理的事项；暂时无法核对的事项保留卡片并标注“等待核验”，不自动播报。临时测试提醒不恢复。电脑唤醒后会重新同步本地事件、音频设备和用量。

接手、批量接手及稍后操作会先写入本机事件目录，即使后台暂时没有响应也能保留，服务恢复后执行。批量接手只针对点击时已显示的事项。

### Codex 剩余用量

菜单栏在波形图标后显示剩余百分比，如 `99%`；有待处理提醒时显示 `99% · 1`。面板的 **Codex 剩余用量** 可查看各额度周期及重置时间，也可手动刷新。

通过本机已安装的官方 Codex 客户端和已有 ChatGPT 登录状态，每分钟读取一次账号用量，并非逐秒实时。多个周期取剩余最少的一项；`usedPercent` 表示已使用，剩余值为 `100 - usedPercent`，向下取整。读取失败、未登录、当前使用 API Key、客户端版本不支持或数据过期时显示 `—`，不会将未知用量显示为 0%。同步失败后自动重试，手动刷新至少间隔 10 秒。

读取的是本机 Codex 客户端当前登录账号的共享额度；切换账号后在下一次同步生效。这里只展示订阅额度百分比，不展示积分余额或 API 费用。

**额度重置时播报** 默认开启，可在用量详情中关闭。当同一账号、同一周期的剩余量从不足 100% 回满，而且服务器的重置时间向后更新时，播报一次，例如“老板，Codex 每周额度已重置，当前总剩余用量百分之 100”。多个周期同时回满会合并播报，文案中的总剩余量仍取各周期最低值。

这是根据成功读数推断的重置事件。首次启动、切换账号或套餐、超过 10 分钟没有可比较的读数时，仅建立基线；数字回满而周期未更新时保持安静。每分钟同步，若重置后已经使用额度，可能错过回满读数。

播报沿用现有音色、语速、称呼和扬声器，只说一次，不新增待处理事项。关闭此开关、关闭语音提醒或暂停期间跳过事件，恢复后不补播；正在播放其他声音时排队，超过两分钟未能播放则略过。**试听重置提醒** 会明确说明是试听，不改变真实额度，可随时停止。

**低额度语音提醒** 默认开启，阈值为 20%。在用量详情输入 1–99% 的整数并点击 **保存**；剩余量严格低于阈值才提醒，等于阈值时保持安静。用量配色也随已保存的阈值调整。

启动或修改阈值后会检查最新有效读数，同一账号、同一额度周期、同一阈值只播报一次，重复刷新及重启会去重；新的额度周期可再次提醒。修改成另一阈值视为新规则，改回本周期已提醒过的阈值不会重复播报。多个低额度周期合并播报，总剩余量仍取各周期最低值；读取失败、数据过期或周期信息无效时保持安静。

低额度播报沿用声音设置，普通任务提醒优先，不生成待处理事项。关闭或暂停时不发声；恢复后若仍低且本周期尚未提醒，会再次检查。音频不可用时不消耗本次提醒机会。**试听低额度提醒** 使用已保存的阈值演示，并明确说明是试听，不改变真实用量。

### 扬声器选择

点击底部设备名，或 **设置 → 切换**。可选择 Mac 内置扬声器、已经连接的蓝牙 / USB / AirPlay 设备、虚拟音频输出，以及 **跟随系统输出**。

指定设备的选择会立即保存，按设备身份识别重连后的设备编号。设备断开、静音或音量为零时暂停，不自动换到其他扬声器。选择“跟随系统输出”时，使用 macOS 当前选择的设备。未显示的设备请先在系统中连接。

使用 macOS 屏幕共享时，声音路径还受共享模式影响。若声音转到远端电脑，请在客户端检查共享连接的声音与显示模式，并重新试听。

## 本地数据与权限

设置和运行数据保存在 `~/Library/Application Support/CodexVoice/`。应用读取当前用户的本地 Codex 事件，观察器仅转发提醒所需元数据。应用不上传聊天记录、音频设备列表或日志，不作审批决定。

用量同步由官方 Codex 客户端联网读取账号限额。小工具只调用初始化、`account/read` 和 `account/rateLimits/read`，不自行读取或保存登录令牌，不发起模型任务、不购买或重置额度。运行快照仅保存经筛选的剩余百分比、周期、重置时间及同步状态，不保存账号邮箱、积分、重置凭证或接口原始响应。提醒功能不依赖用量同步成功。

为避免切换账号被误判为重置，账号接口返回的标识或邮箱只在内存中转换为比较用的哈希，该比较字段不进入快照或设置文件；重置检测在重启后重新建立基线。播报开关和低额度阈值保存在本机设置中。

低额度提醒的去重记录保存在 `usage-low-alerts.json`，只包含按账号、额度周期、阈值生成的事件哈希及过期时间，不包含邮箱或原始账号数据，文件权限为 `0600`。记录在语音实际启动后写入，因此暂停或音箱未连接时不会提前消耗提醒机会。

恢复检查点保存在 `reminder-state.json`，包含必要的提醒元数据、已处理标记和本地事件文件读取位置，权限为 `0600`；不保存完整聊天正文或登录凭据。写入采用临时文件替换，损坏的记录会跳过，较早或暂不能核实的事项以卡片状态保留。

连接安装器只增加本应用的 5 个观察器，备份原 `hooks.json`，保留其他观察器与审批策略；不写入 Hook 信任记录。新定义仍需用户在 Codex 中审核。可在 Codex 的 `/hooks` 中禁用或移除观察器。

删除应用前，可先关闭登录自启并退出。需要清理连接时，在 `/hooks` 中移除本应用的观察器；运行数据可自行备份后删除。

## 从源码构建

需要 macOS、Xcode Command Line Tools 和用于构建脚本的 Python 3.9 及以上。运行环境下载自 Python 官方网站，版本与 SHA-256 固定在 `scripts/python-runtime.json`。

```sh
PYTHONPATH=src python3 -m unittest discover -s tests -v
python3 scripts/build.py --package
python3 scripts/verify_app.py '.build/Codex 语音提醒.app'
```

应用位于 `.build/`，DMG、ZIP 和校验值位于 `dist/`。构建仅解包官方 Python 安装器，不向系统安装 Python。默认使用临时签名；有 Developer ID 证书时可传 `--identity`，正式分发还需要按 Apple 流程完成签名、公证与验证。
