# Codex Passport 随身提醒工牌：首个原型

已确定的用法是在 Mac 附近随身佩戴。Mac 负责 Codex 事件采集、提醒安排、免打扰、用量读取和已接手状态；工牌通过加密蓝牙显示有限数量的状态、播放七段预置语音并回传按键操作。无需手机中转、配置 Wi-Fi 或新增模型 API。

## 操作与行为

- 上、下键：切换可见提醒。优先显示最需要处理的事项，最多八条；电脑保留全部事项及总数。接手当前事项后，后续事项继续进入可见列表。
- 短按确认：表示这条提醒已接手；不会代替你批准 Codex 工具操作或回答问题。
- 长按确认：打开菜单，包含返回、稍后5分钟、重播提醒、静音15分钟和重新配对。取消配对还需要在工牌上再次确认。
- 首次配对：在电脑小工具的输出设备列表中选择 AI Passport，允许 macOS 蓝牙权限；系统询问时，输入工牌屏幕上的六位配对码。
- 三十秒后屏幕变暗；第一次唤醒按键不执行接手操作，避免误触。
- 心跳失效后清除过期任务并停止播放；重连后同步电脑当前状态。按键操作必须收到电脑状态确认后才显示成功。
- 电量读取使用 CW2017 现有的有效配置，不替换电芯校准参数；不可用时显示横线。
- 新观测到的 Codex 轮次显示为执行中；没有待处理提醒不表示所有项目已完成。事件覆盖范围沿用现有电脑工具对本地会话的支持边界。

## 语音

此原型使用 Mac 生成并写入固件的 Tingting 固定语音，格式为16 kHz、16位、单声道 PCM。屏幕显示任务名，固定语音暂不朗读任务名。工牌不跟随电脑的音色、称呼和语速设置；完整任务名语音作为后续增量。

现有 Python 引擎统一管理提醒。收到匹配的“设备开始播放”反馈后，才推进该提醒的播报次数。断线、超时、播放失败均不计入成功次数。选择工牌后只向工牌播报；选择 Mac 扬声器则使用原有行为。

## 协议和资源归属

服务 UUID 为 EA37F001-4E2B-47EF-9501-6D79B932A001；RX、TX 分别将 F001 改为 F002、F003。版本1协议使用有长度上限的 UTF-8 JSON 行；分片合并后解析，超长帧丢弃到下一处换行后恢复。

Mac 原生模块管理 CoreBluetooth，发送 hello、state、play、stop、action_result；工牌发送 hello、pong、audio、action。状态使用每次启动随机生成的会话标识和提醒ID哈希，只传所选任务标题、类别、数量、静音状态及有效用量百分比，不发送聊天全文、凭据或原始账号数据。回传操作仅允许接手、稍后、重播、暂停。

工牌十秒没有更新即让状态失效；Mac 十二秒没有设备反馈即重连。电脑引擎快照过期时禁用工牌播放。音频由独立工作任务分块送入 DMA，通过取消代数中断；蓝牙和按键回调不执行音频或 LVGL 工作。

## 开发与验证

固件基于官方 main 的 006c2279852e352a8433b2c21e5e09be2ca36f77，使用 ESP-IDF 5.5.3。相邻 codex-voice 仓库使用 feature/passport-companion 分支，基线为 5bc4c097699be224cfd5a2ee9dfbe2658d57e3f2。本次没有提交、推送或发布要求。

激活 ESP-IDF 后运行统一检查 ./tools/validate.sh，包含新增的状态、分帧及只读电量计测试。Mac 端运行 Python 单元测试、PassportProtocol 原生测试、通用架构应用构建及 scripts/verify_app.py。成功后应记录最终验证证据及合并固件的精确标识。

设备识别已完成：ESP32-C3 revision 1.1、8 MB闪存、USB Serial/JTAG；用户已确认只读检查后原名片正常启动。用户已授权并刷入首版，基础配对、中文显示、声音、确认键同步和电脑端重启后自动重连已通过；其余菜单、续航、距离和长期稳定性仍待验证。参见[实机验证记录](codex-companion-validation.zh_CN.md)。

## 刷入影响

遵循[开发指南的实机测试交接](development/ai-guide.zh_CN.md#offer-on-device-testing)。仅在获得明确同意后，将校验通过的合并固件从0x0刷入。它会替换当前名片应用，并可能重置原名片设置。本方案不执行整片擦除；没有验证前不承诺恢复原程序或具体续航。

## 资源

字体采用 Noto Sans SC 的500字重，随附 SIL Open Font License。参见[字体源文件](../assets/fonts/NotoSansSC-wght.ttf)、[许可证](../assets/fonts/NotoSansSC-OFL.txt)及[资源清单](../assets/music/codex/manifest.json)。生成的16像素字体覆盖常用汉字和标点，未支持的标题字符明确显示方框；生成时检查固定界面的源字体字形。使用 fontTools、lv_font_conv 1.5.3 运行 tools/make_companion_assets.py；可通过 --audio-only、--fonts-only 单独生成资源。实际屏幕效果和声音质量仍需在工牌上确认。

## 当前使用与恢复

当前临时运行“Codex 工牌联调”，已选择 AI Passport 蓝牙工牌。原版应用没有被覆盖。短按确认键只表示接手提醒；实际审批或回答仍在 Codex 中处理。屏幕三十秒后自动调暗，首次按键只负责唤醒，稍等后再按可操作。

如需恢复原版，先在联调版将播报设备切回本次原有的“跟随系统输出”，退出联调版，再打开应用程序文件夹内的原版。原设置快照仅保存在本地 build/mac-settings-before-passport.json，不应上传。
