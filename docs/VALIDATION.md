# v0.9.1-beta.1 发布验证

日期：2026-10-25。Mac 内部构建号 37，嵌入 Python 3.14.8，部署目标 macOS 13，听写要求 macOS 26。应用与音频工具包含 arm64 / x86_64。验证机器为 Apple 芯片 Mac、macOS 27；硬件为一张 FoloToy AI Passport。

## Mac 构建与主机测试

- 193 项 Python 测试通过，包含已有提醒/恢复/用量和新增独立配件设置、迁移、输出、宠物来源测试。
- Swift 原生测试通过：协议与隐私筛选、音频帧/重复/缺包/文本编辑、独立临时剪贴板格式和恢复、生成图像方向/尺寸/传输边界/续传/暂停/校验切换。
- 双架构生产构建完成，完整临时签名校验通过。安装包自带 Python，无需使用者的系统 Python。
- 打包应用在含空格的移动路径、干净 PATH 与独立状态目录运行通过；内嵌 Python、标准库、Hook 入口及配置保存/重启恢复通过。
- 模拟工牌应答、接手停止、断线不消耗计数、旧设置迁移和独立配件设置持久化通过；这是模拟引擎检查，不代替 BLE 实测。
- README 截图来自真实 SwiftUI 视图及隔离演示状态；界面渲染覆盖空闲、任务、多事项、低额度、离线、深色、用量详情和设置。

## 实际界面与此前硬件联调

同一实现的本地构建已实测：单个首页总开关、声音输出页独立电脑播报、指定卡片顺序、小圆环/详情大圆环、完整订阅卡片、蓝色收起按钮、点击外部/切换应用自动收起、现有昵称保留、登录启动项及 BLE 自动重连。

在本次打包前，用户已在同一 Apple 芯片 Mac 和 AI Passport 上确认：电脑/工牌同时播报、工牌昵称正确、切换 Codex 宠物后自动更换形象、真人中文听写直接落字、不弹保留面板、不自动发送、开始/完成音干净、中英文输入法切换不再卡顿。

发布版 Mac 仅将已验收的本地 0.9.1-home.2 标识提升为 0.9.1-beta.1，并整理构建/打包和公开文档；没有为发布再次操作用户的输入框或麦克风。当前已安装应用保持原位，不因 GitHub 发布重新登记系统权限。
