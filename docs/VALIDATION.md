# v0.5.0-beta.1 验证记录

验证平台：Apple 芯片 Mac，macOS 27.0.1。构建部署目标为 macOS 13，应用、音频检测工具与嵌入 Python 运行环境都包含 arm64 / x86_64 两种架构。

## 已完成

- 31 项单元检查通过，覆盖提醒退避、接手、稍后、暂停、不同聊天隔离、审批观察、扬声器选择与保存、断开保留、Hook 安装与原配置保留。
- 从 Python 官方下载 3.14.8 运行环境，核对固定 SHA-256。
- 应用复制到含空格的新目录，以不含 Homebrew / 用户 Python 的 PATH 启动：Python、SQLite、标准库全部从应用内部加载。
- 在临时配置目录安装 5 个观察器，并使用应用内 `--hook` 入口写入测试事件；未创建或改写 Codex 审批策略与信任配置。
- 应用及嵌套代码的完整签名校验通过。此项验证文件完整性，不等于 Apple Developer ID 签名或公证。
- ZIP 解包后完整签名校验通过；DMG 完整性校验通过。
- 本机安装到应用程序目录，迁移已有设置，保留原 5 个已授权观察器；已有 Codex 配置字节保持不变，安装后仍观察到 Hook 事件。
- 通过原生界面正常退出，退出码为 0；重新按应用路径打开后，新进程与提醒服务正常运行，保留扬声器选择和已开启的登录自启。
- 实际检查空闲面板、多条提醒卡片、长标题、设置页、设备选择页，以及提醒开关、登录自启、设备保存与重启恢复。
- 公开源码与应用可执行文件检查未发现开发机器的用户名、工作目录或设备标识；安装包不含本机设置与运行记录。

## 未完成 / 不作保证

- 当前机器没有 Rosetta，未执行 Intel 架构代码；未在 Intel 物理机或 macOS 13–26 上验收。
- 未完成 Apple Developer ID 签名与公证，下载后的 Gatekeeper 首次打开流程仍需用户检查来源并按系统提示处理。
- 未验证其他人的真实 Codex 账号、受管策略、AirPlay 物理播放、云端或远程执行环境。
- Codex 的本地事件存储是兼容适配，内部格式变化后可能需要更新。
