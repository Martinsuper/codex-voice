# v0.6.0-beta.1 验证记录

日期：2026-10-19。验证平台：Apple 芯片 Mac，macOS 27.0.1。部署目标为 macOS 13，发行包包含 arm64 / x86_64 架构。内部构建号 8。

## 已完成的功能验证

- 158 项单元检查全部通过，覆盖声音设置、暂停、设备选择、聊天隔离、Hook 兼容，以及分类规则、限次、独立间隔、定时免打扰、用量、额度提醒和恢复去重。
- 应用内 Python 3.14.8 在含空格的新目录和干净 PATH 中运行：伴随模块来自应用 Resources，配置真实写盘并在重启后恢复，非法配置不覆盖已有设置。本版最终发行构建再次通过此检查，并核对应用与引擎版本均为 0.6.0-beta.1。
- 在独立 Codex 配置中安装 5 个观察器，验证应用内 Hook 入口；安装器保留其他观察器，不创建或修改信任及审批配置。
- 原生界面完成浅色、深色、长标题、多卡片与较矮窗口检查。实际操作称呼、间隔、暂停、低额度阈值、分类规则和免打扰表单，核对保存与非法值拒绝。测试使用隔离配置和模拟音频输出。
- 实际点击卡片右侧大按钮边缘，验证完整点击区域；开关在失焦后维持实际状态色。真实菜单栏定位记录的气泡三角偏差为 0、间隔为 1；多屏及负坐标边界另有坐标模拟检查。
- 本机官方 Codex 客户端 `0.163.0-alpha.10.2` 的只读账号及用量接口读取成功，已安装应用能显示并更新剩余百分比。未发起模型任务、购买或消耗额度重置。
- 离线 App Server 协议样例串联真实用量模块与打包引擎：验证回满并推进周期后的单次重置播报、首次基线、切换与重复读取抑制，以及低额度阈值变更、跨重启和新周期去重。
- 慢用量查询期间，新建并接手提醒约 0.42 秒，退出约 0.74 秒且读取子进程收尾。协议仅发送初始化与两个账号只读方法。
- 使用系统音色生成非空 AIFF 文件，验证称呼和语速；未逐一试听全部系统音色。额度语音样例未播放，未改动真实账号额度。
- 原生服务管理代码连接应用内引擎，对测试自己创建的服务发送 SIGKILL / SIGSTOP：异常退出约 1.23 秒恢复，挂起约 25.90 秒恢复；待办保留，挂起期间接手可持久化，接手后再恢复不复活。
- 验证有界重试、进程组归属及模拟睡眠/唤醒；退出时能收尾挂起的测试服务。未让整台 Mac 实际睡眠验收。
- 恢复检查点与事件目录检查覆盖停机期间的回复、完成和归档，损坏记录、中断播报、旧回复重放和批量接手范围；不能核实的旧事项保持卡片，不自动播报。
- 此前本地安装验收保留了原有设置、5 个 Hook、Codex 审批配置和登录自启配置；新功能页面和服务就绪。发行构建的配置兼容性已在隔离配置中再次核对；个人运行数据不进入安装包。
- 公开文件检查未发现本机运行数据、账号配置或 `local/` 内容；本机记录与备份均排除在 Git 同步之外。
