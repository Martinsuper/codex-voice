Codex 语音提醒 v0.6.0-beta.1 — 安装与使用

从旧版升级
1. 在旧版设置中点击“退出应用”。
2. 将新版“Codex 语音提醒.app”拖入 Applications（应用程序），替换同名应用。
3. 从应用程序或 Spotlight 搜索“Codex 语音提醒”并重新打开。
保持原路径 /Applications/Codex 语音提醒.app，可保留原设置、扬声器、登录自启及已有的5个观察器。新选项使用默认值。
不要同时运行旧版与新版；不要删除运行数据文件夹。

首次安装
1. 将“Codex 语音提醒.app”拖入 Applications 并打开。
2. 点击菜单栏波形图标，底部设备名可选择扬声器。
3. 在设置中点击“连接 Codex”，审阅说明后安装观察器。
4. 在 Codex CLI 的 /hooks 中检查并信任新增的5个观察器。
   应用不会自动信任 Hook，也不会代替你批准 Codex 的操作。
5. 点击“试听一下”测试提醒，听到后点“已接手”停止。
改变应用路径或连接失效时，请重新连接并检查 /hooks。

新功能入口
- 设置 → 声音与规则 → 调整：音色、语速、称呼、重复间隔及单次试听。
- 暂停右侧箭头：预设时长或自定义1–1440分钟，记住上次选择。
- 设置 → 按类型设置提醒：四类语音开关、次数和独立间隔，修改后保存。
- 设置 → 定时免打扰：每周日期、跨午夜时段和审批例外，默认关闭。
- Codex 剩余用量：各周期、手动刷新、额度重置播报、低额度阈值及试听。
- 后台服务异常时自动恢复，唤醒后重新同步；主动退出应用仍会结束运行。

菜单栏额度约每分钟同步，多个周期取最低剩余值。
用量依赖本机已安装的官方 Codex 及已有 ChatGPT 登录，需要支持账号用量接口。
未登录、使用 API Key、客户端不支持或读数无效时显示“—”，不影响任务提醒。
低额度默认低于20%提醒，可设置为1–99%；额度重置为成功读数推断，可能漏过已开始消耗的周期。

误退出后：从应用程序或 Spotlight 再次打开。
登录自启：设置中启用“登录后自动启动”。
接手只停止提醒，审批仍需回到 Codex 原聊天处理。

适用范围：macOS 13+，内含 Apple 芯片与 Intel 两种架构。
已在 Apple 芯片 Mac 上验证；Intel 和旧系统仍需实机验收。
无需安装 Python、Homebrew，也不需要填写 API Key。
需要支持 Hooks 的本地 Codex，云端、远程执行及受管环境不保证覆盖。

当前是未完成 Apple Developer ID 签名和公证的测试版。
首次打开可能被 macOS 提示或阻止。请先核对仓库与校验值，
只在确认来源可信后，按照系统“隐私与安全性”中的提示处理。

任务提醒在本机处理，不上传聊天记录、设备列表或运行日志。
额度通过官方客户端只读查询，不发起模型任务，不购买或消耗额度重置。
设置与运行数据：~/Library/Application Support/CodexVoice/
项目、更新日志与反馈：https://github.com/superslash-rico/codex-voice
