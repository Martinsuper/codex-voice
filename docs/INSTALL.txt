Codex 语音提醒 v0.9.1-beta.1 — 安装与使用

一个软件，两种用法：没有工牌也可正常使用电脑提醒；有 AI Passport 时可独立启用硬件配件。

首次安装
1. 将“Codex 语音提醒.app”拖入 Applications（应用程序），再从应用程序中打开。
2. 点击菜单栏波形图标，在设置中点“连接 Codex”，阅读说明后安装本地观察器。
3. 在 Codex CLI 的 /hooks 中审阅并信任新增的5个观察器。
   应用不会替你信任 Hook，也不会代替你批准 Codex 的操作。
4. 点击首页“试听一下”，听到后点击“已接手”停止。
5. 点击首页扬声器卡片进入“声音输出”，选择扬声器，并单独控制“电脑播报”。
6. 需要开机登录后启动时，在设置中开启“登录后自动启动”。
同时使用 OpenCode 时：在设置中点“OpenCode 连接”安装本地观察插件，重启 OpenCode 生效；只用 OpenCode、不用 Codex 也能正常提醒。

从旧版升级
先在旧版设置中退出应用，再替换 /Applications/Codex 语音提醒.app，重新打开。
保持原安装路径可保留提醒规则、扬声器、昵称、登录自启和已有 Hook 连接。
不要同时运行旧版与新版，不要删除运行数据文件夹。
本测试版采用临时签名；升级后若听写不能落字，请在系统“设备控制和数据访问”
（部分系统叫“辅助功能”）中移除旧的本应用项，再重新添加并开启新版同名应用。

首页与声音
- 顶部总开关控制任务和额度提醒，关闭立即停播并清空当前提醒；再开启只接收新事项。
- 电脑播报只控制电脑出声；AI Passport 播报可以独立开启，或和电脑同时开启。
- 首页顺序：扬声器、提醒与待处理、小圆环用量、AI Passport。
- 点击用量查看大圆环、各周期和重置时间；约每分钟同步，多个周期取最低剩余值。
- 点击“收起面板”或切换到其他应用可收起；后台提醒服务继续运行。
- “已接手”只停止提醒，实际审批、回答与发送仍在 Codex 原聊天完成。
- 设置可调整音色、语速、称呼、重复间隔、分类提醒、暂停时长及定时免打扰。

AI Passport（可选）
先按项目的 AI Passport 指南刷入配套固件，再在首页 AI Passport 设置中启用配件。
首次连接需允许蓝牙，并在 Mac 配对窗口输入工牌显示的六位码。
连接后可同步任务、用量和宠物；电脑与工牌播报分别开关。
新用户宠物昵称默认“Codex”，可改为1至8个中文、英文或数字；升级保留已有昵称。
在 Codex 中切换宠物后后台自动同步，完成前保留旧形象；没有宠物时使用固件默认形象。
工牌不需要连接 Wi-Fi；Mac 需要在附近且本应用运行、蓝牙开启。
同一工牌也可刷第三方 Piko Wi-Fi 固件：同一局域网直连电脑，仅支持按住听写，详见项目指南路线 C。

按住听写：需要 macOS 13+、应用内置的简体中文识别模型和本应用的辅助功能权限。
先点选电脑输入框，长按工牌确认键，听到开始单音后讲话；松开停止。
上扬双音表示文字已写入输入框，不代表消息已经发送。消息由你手动发送。
识别失败或目标改变会在工牌提示；保留的文字可在听写设置中查看和复制。
录音在本机内存中识别，不上传、不保存音频文件；Piko Wi-Fi 固件经局域网明文传输原始录音，仅适合可信网络。

系统与权限
普通提醒和工牌同步面向 macOS 13+；安装包含 Apple 芯片与 Intel 两种架构。
工牌听写需要 macOS 13+，当前只提供简体中文识别；识别模型已随应用内置。
使用者无需安装 Python、Homebrew，不需要填写 API Key。
用量需要本机支持账号接口的官方 Codex 和 ChatGPT 账号登录；不可用时显示“—”。
当前适配本机 Codex；远程、云端、受管环境、特殊审批不保证覆盖。
已在 Apple 芯片 Mac 上验证；Intel 和较旧系统未实机验收。

当前测试版尚未完成 Apple Developer ID 签名与公证。
首次打开如被 macOS 阻止，先核对 GitHub 来源及 SHA-256，按系统安全提示处理。
安装包不关闭 Gatekeeper，不自动移除隔离属性。
