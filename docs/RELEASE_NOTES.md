# Codex 语音提醒 v0.6.0-beta.1

这一版把声音与提醒规则做成可配置，加入 Codex 用量提醒、后台自动恢复和定时免打扰。

## 本次更新

- **声音可配置**：选择系统音色、语速、称呼和三档重复间隔，支持单次试听、停止和恢复默认。
- **操作更方便**：接手按钮移到卡片右侧并放大，“知道了”以红色突出显示；开关失焦后保留真实状态色，面板顶部气泡三角指向菜单栏图标。
- **暂停可自定义**：预设时长或输入 1–1440 分钟，记住上次选择，支持仅保存或保存并暂停。
- **菜单栏显示剩余额度**：约每分钟同步，详情查看各周期及重置时间，支持手动刷新；不可用显示 `—`。
- **额度语音提醒**：推断额度重置时播报一次，低于自定义阈值时提醒（默认 20%，范围 1–99%）。可分别关闭及试听，不创建待办。
- **后台自动恢复**：服务退出或无响应后有界重试，保留事项、暂停和稍后期限；先核对已处理事件，再恢复播报。唤醒后重新同步。
- **按类型设置**：完成、审批、提问、异常可分别控制语音、最多次数和重复间隔；默认保持原有行为。
- **定时免打扰**：设置每周日期、跨午夜时段和审批例外，默认关闭；结束后只提醒仍未处理的事项。

完整记录见 [更新日志](https://github.com/superslash-rico/codex-voice/blob/v0.6.0-beta.1/CHANGELOG.md)。

## 下载、安装与升级

下载 **CodexVoice-0.6.0-beta.1-universal.dmg**，将“Codex 语音提醒.app”拖入 Applications。也提供 ZIP 和 `SHA256SUMS.txt`。

**升级用户：先在旧版设置中退出应用，再替换 `/Applications/Codex 语音提醒.app` 并重新打开。** 原有声音、扬声器、规则、暂停和登录自启等设置保留，新选项使用默认值。同一路径的已有观察器可继续使用。

**首次安装用户：** 打开后在设置中连接 Codex，再在 Codex CLI 的 `/hooks` 中审阅并信任 5 个观察器。应用不会自动信任 Hook，也不代替你审批。改变安装路径或连接失效时需重新连接。

无需安装 Python、Homebrew 或填写 API Key。用量功能需要本机已安装支持账号用量接口的官方 Codex，并使用 ChatGPT 账号登录；否则用量显示 `—`，任务提醒仍可独立使用。

设置入口：**声音与规则 → 调整**、**按类型设置提醒**、**定时免打扰**；额度开关、阈值和试听位于 **Codex 剩余用量** 详情。

## 验证与测试版边界

158 项单元检查已通过，并完成内嵌运行环境、移动目录、配置写盘与重启、Hook 隔离安装及服务故障恢复验证。安装包的验证范围见 [验证记录](https://github.com/superslash-rico/codex-voice/blob/v0.6.0-beta.1/docs/VALIDATION.md)。

面向 macOS 13+，包含 arm64 / x86_64 两种架构。已在 Apple 芯片 Mac 实机运行，Intel 与旧 macOS 尚未实机验收。

**此包尚未完成 Apple Developer ID 签名与公证。** 首次打开可能被 macOS 提示或阻止，请核对仓库来源与校验值，再按系统“隐私与安全性”提示处理。

用量并非逐秒实时；额度重置由读数推断，首次同步只建立基线，重置后已开始消耗时可能错过播报。远程 / 云端任务、受管环境和特殊连接器审批不保证覆盖。
